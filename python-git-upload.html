🐙 رفع مشروع Python إلى GitHub من الهاتف

الآن وقد كتبت أول سكربتات Python، حان وقت رفعها إلى GitHub للحفظ والمشاركة. سأشرح الطريقة التي استخدمتها بالضبط من الهاتف.

📁 تنظيم المشروع

أنشئ مجلدًا جديدًا لمشروعك:

mkdir my-python-project && cd my-python-project

ضع بداخله ملفات Python التي كتبتها (مثل hello.py، files.py) بالإضافة إلى README.md لشرح المشروع.

📄 إنشاء README.md بسيط

nano README.md

محتوى مقترح:

# My Python Project
مشروع Python بسيط من إنشائي على الهاتف باستخدام Termux.
## الملفات
- hello.py: أول سكربت ترحيبي
- files.py: عرض ملفات المجلد الحالي

🔗 ربط المجلد بـ GitHub

يفضل إنشاء مستودع جديد على GitHub باسم المشروع (فارغ، بدون README). ثم من داخل المجلد نفذ:

git init
git add .
git commit -m "أول نسخة من مشروع Python"
git branch -M main
git remote add origin git@github.com:moheynasir-ctrl/my-python-project.git
git push -u origin main

🔄 تحديث المشروع لاحقًا

عند تعديل ملف أو إضافة جديد:

git add .
git commit -m "وصف التغيير"
git push
💡 نصيحة: ارفع كل مشاريعك إلى GitHub حتى لو كانت بسيطة. هذا يبني سجلًا قويًا كمطور، ويمكنك الرجوع لها من أي جهاز.
