🔐 إنشاء مفتاح SSH والاتصال الآمن

في هذا الدرس، سأشرح كيفية إنشاء مفتاح SSH وربطه بـ GitHub، لتتمكن من رفع مشاريعك بدون كتابة كلمة مرور كل مرة. هذا هو الأساس الذي استخدمته لبناء هذا الموقع.

📦 تثبيت OpenSSH

pkg install openssh -y

🔑 توليد المفتاح

ssh-keygen -t ed25519 -C "moheynasir@gmail.com"

عند السؤال عن مكان الحفظ، اضغط Enter للقبول بالمكان الافتراضي. وعند سؤاله عن كلمة مرور، اتركها فارغة (Enter).

🚀 تشغيل ssh-agent وإضافة المفتاح

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

📋 نسخ المفتاح العام

cat ~/.ssh/id_ed25519.pub

انسخ الناتج كاملاً (يبدأ بـ ssh-ed25519 وينتهي ببريدك).

🔗 إضافة المفتاح إلى GitHub

اذهب إلى: github.com/settings/keys، واضغط New SSH Key، وألصق المفتاح، ثم احفظ.

✅ اختبار الاتصال

ssh -T git@github.com

إذا نجح، ستظهر رسالة ترحيب باسم مستخدمك. الآن يمكنك استخدام Git مع GitHub دون إدخال أي كلمة مرور.

💡 خلاصة تجربتي: هذا المفتاح هو بوابتك الآمنة. أنشئه مرة واحدة فقط على كل جهاز، واستخدمه لجميع مستودعاتك. لقد وفر علي عناء كتابة البريد وكلمة المرور في كل Push.
