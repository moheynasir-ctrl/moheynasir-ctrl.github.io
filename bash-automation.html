🤖 سكربت Bash لأتمتة المهام اليومية

في هذا الدرس، سأشاركك سكربتات Bash التي أستخدمها لتوفير الوقت في Termux. الأتمتة هي سر المطور الذكي.

📜 سكربت التحديث اليومي

أنشئ ملف update.sh:

nano update.sh

واكتب بداخله:

#!/bin/bash
echo "جاري تحديث الحزم..."
pkg update && pkg upgrade -y
echo "تم التحديث بنجاح!"

اجعل الملف قابلاً للتنفيذ:

chmod +x update.sh

وشغّله:

./update.sh

📁 سكربت عرض حالة المشروع

أنشئ status.sh:

nano status.sh

واكتب:

#!/bin/bash
echo "📂 المجلد الحالي: $(pwd)"
echo "📄 عدد الملفات: $(ls | wc -l)"
echo "💾 المساحة المتبقية:"
df -h /data

اجعل الملف قابلاً للتنفيذ وشغّله:

chmod +x status.sh && ./status.sh

🔄 سكربت رفع المشروع إلى GitHub بضغطة واحدة

أكثر سكربت أستخدمه! أنشئ push.sh:

nano push.sh

واكتب:

#!/bin/bash
git add .
echo "أدخل وصف التغيير:"
read msg
git commit -m "$msg"
git push
echo "✅ تم الرفع بنجاح!"
💡 نصيحة: تعلم Bash حوّل هاتفي إلى أداة إنتاجية حقيقية. بدلاً من كتابة عدة أوامر كل مرة، صرت أنفذ سكربتاً واحداً. جرب كتابة سكربتاتك الخاصة!
