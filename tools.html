⚙️ أدوات المطور

هذه الأوامر التي استخدمتها لتجهيز بيئة تطوير كاملة على هاتفي.

Python

pkg install python -y
python --version

يثبت Python وتتأكد من الإصدار المثبت.

Git و GitHub

pkg install git -y
git config --global user.name "المطور محمد حميدان"
git config --global user.email "moheynasir@gmail.com"
pkg install openssh -y
ssh-keygen -t ed25519 -C "moheynasir@gmail.com"
cat ~/.ssh/id_ed25519.pub

يثبت Git، يعرفه، يجهز SSH لربط GitHub بدون كلمة مرور.

Kali Nethunter

bash install-nethunter-termux
nethunter

بعد تحميل ملف rootfs، هذا الأمر يشغل بيئة Kali كاملة.
