📘 أساسيات Termux

هنا أوثق الأوامر التي أستخدمها يومياً داخل Termux. هذه تجربتي الشخصية، قد تختلف عندك.

تحديث النظام والحزم

pkg update && pkg upgrade -y

يقوم بتحديث قائمة الحزم ثم ترقية كل شيء إلى أحدث إصدار.

الوصول للتخزين

termux-setup-storage

يعطي صلاحية لتصل إلى ملفات هاتفك عبر مجلد ~/storage.

التنقل بين المجلدات

ls        # عرض الملفات في المجلد الحالي
cd ..     # الرجوع للمجلد الأب
cd ~      # الذهاب لمجلد home
