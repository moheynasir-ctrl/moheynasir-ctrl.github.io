📱 كيف بنيت هذا الموقع بالكامل من هاتفي

أنا المطور محمد حميدان، وهنا أوثق رحلتي لبناء موقع شخصي يعمل كهاتف محمول فقط، باستخدام Termux وGitHub Pages. كل خطوة نفذتها ستجدها هنا مع الأكواد الجاهزة.

🛠️ الأدوات المستخدمة

  • Termux - محاكي Linux على الأندرويد
  • Git - لإدارة النسخ ورفع الملفات
  • GitHub Pages - استضافة مجانية للمواقع الثابتة
  • محرر nano - لكتابة الأكواد داخل Termux

🚀 الخطوات بالتفصيل

1. تثبيت Termux وإعداد التخزين

بعد تثبيت Termux من F-Droid، نفذت:

termux-setup-storage

ثم حدثت الحزم:

pkg update && pkg upgrade

2. تثبيت Git وربطه بحساب GitHub

pkg install git -y

تعيين الهوية:

git config --global user.name "المطور محمد حميدان"
git config --global user.email "moheynasir@gmail.com"

توليد مفتاح SSH والاتصال بـ GitHub (باستخدام الأمر ssh-keygen وإضافة المفتاح في إعدادات GitHub).

3. إنشاء مجلد المشروع وملف HTML الأول

mkdir ~/my-digital-library && cd ~/my-digital-library
nano index.html

كتبت كود HTML بسيطاً باليد، ثم حفظت الملف.

4. رفع المشروع إلى GitHub

git init
git add index.html
git commit -m "أول نسخة من المكتبة الرقمية"
git branch -M main
git remote add origin git@github.com:moheynasir-ctrl/moheynasir-ctrl.github.io.git
git push -u origin main

5. تفعيل GitHub Pages

بما أن المستودع اسمه moheynasir-ctrl.github.io، يتم نشر الموقع تلقائياً على الرابط https://moheynasir-ctrl.github.io خلال دقيقة واحدة من الدفع.

💡 نصيحة: كل مرة أردت فيها تحديث الموقع، أفتح Termux، أعدل الملفات، ثم أرفع التغييرات بنفس أوامر git.
