📘 أوامر Termux الأساسية التي أستخدمها

هذه مجموعة الأوامر الأساسية التي أستخدمها يومياً في Termux على هاتفي. سأشرح كل أمر بطريقة عملية، وكأنني أتحدث إلى نفسي عندما بدأت.

🔄 تحديث النظام والحزم

pkg update && pkg upgrade

أول أمر أنفذه بعد تثبيت Termux. يجلب قائمة الحزم المحدثة ويرفع النسخ المثبتة.

📁 التنقل بين المجلدات

pwd - يعرض المسار الحالي
ls - يعرض محتويات المجلد
cd ~ - العودة للمجلد الرئيسي
cd .. - الرجوع خطوة للخلف

📄 إدارة الملفات والمجلدات

mkdir اسم_المجلد - إنشاء مجلد
touch اسم_الملف - إنشاء ملف فارغ
nano اسم_الملف - فتح الملف للتحرير
rm اسم_الملف - حذف ملف
rm -rf اسم_المجلد - حذف مجلد بمحتوياته

📦 تثبيت الأدوات

pkg install git - لتتبع المشاريع
pkg install python - لكتابة السكربتات
pkg install openssh - للاتصال الآمن

يمكن البحث عن أي أداة باستخدام: pkg search اسم_الأداة

🧹 تنظيف وتوفير مساحة

pkg clean - يحذف ملفات التثبيت المؤقتة
pkg autoclean - يحذف الحزم القديمة غير المستخدمة
💡 نصيحتي لك: لا تحفظ الأوامر، بل افهم ما تفعله. جرب كل أمر بنفسك، وستصبح سريعاً قادراً على العمل دون الرجوع للمراجع.
