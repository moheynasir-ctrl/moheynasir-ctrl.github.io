🧩 كيف بنيت هذا الموقع من الهاتف

هذا توثيق كامل للخطوات التي اتبعتها لبناء ونشر هذا الدليل على GitHub Pages باستخدام Termux فقط.

الخطوات

1. أنشأت مجلد العمل: mkdir my-digital-library
2. أنشأت ملف index.html و style.css
3. بدأت Git: git init
4. أضفت الملفات: git add .
5. أول commit: git commit -m "النسخة الأولى"
6. ربطت المستودع البعيد: git remote add origin git@github.com:moheynasir-ctrl/moheynasir-ctrl.github.io.git
7. رفعت الملفات: git push -u origin main
8. زرتُ الرابط: https://moheynasir-ctrl.github.io
